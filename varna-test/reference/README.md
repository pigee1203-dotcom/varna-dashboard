# Point de départ

`varna-actuel.tar.gz` est une copie locale du code, des ressources publiques et des fichiers de configuration de VARNA au moment de la création du laboratoire.

Elle ne contient ni `.env.local`, ni `.git`, ni `node_modules`, ni les fichiers de compilation, ni les données stockées dans le navigateur. Cette archive est une référence, pas une sauvegarde des comptes ou des données utilisateur.

Ne pas extraire cette archive par-dessus le projet principal sans une demande explicite.
